6. 占位符

   1. %g 是 Go 的 fmt 中用于浮点数的格式占位符：它会在**科学计数法 %e 和普通小数 %f** 之间自动选择更紧凑的一种，并去掉多余的尾随 0

   2. %G是在%E和%f之间自动选择

   3. | 占位符    | 名称            | 作用                                      | 输出示例 (`s := []int{2,3}`) |
      | :-------- | :-------------- | :---------------------------------------- | :--------------------------- |
      | **`%v`**  | 默认格式        | 仅打印值，不附带类型                      | `[2 3]`                      |
      | **`%+v`** | 带字段名        | 打印结构体时带字段名（对切片效果同 `%v`） | `[2 3]`                      |
      | **`%#v`** | **Go 语法表示** | **带类型**的完整 Go 语法片段（调试首选）  | `[]int{2, 3}`                |
      | **`%T`**  | 类型表示        | 仅打印变量的**类型**                      | `[]int`                      |
      | **`%p`**  | 指针地址        | 打印底层**内存地址**                      | `0xc000012330`               |

7. defer 延迟执行

   1. 参数会在 `defer` 语句执行时**立即求值**

   2. 使用栈，后进先出

   3. defer的核心价值并不是**延迟**，而是**兜底保障**

      ```
      for i := 0; i < 2; i++ {
          func(i int) {
              f, _ := os.Open("file.txt")
              defer f.Close() // 注册清理动作
              // ... 读取操作 ...
              // 即使这里发生 panic，或者我写了 return，
              // f.Close() 也绝对会被执行！
          }(i)
      }
      # 上述这种写法虽然在循环中失去了后进先出的规则，但可以保证无法发生什么，资源都能得到释放，因为defer在函数返回前执行
      ```
