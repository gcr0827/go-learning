1. 指针

   1. 指针就是一个变量，它存储的不是普通数据（如整数、字符串），而是另一个变量在内存中的地址。通过这个地址，你可以直接访问或修改那个变量

   2. **取地址（`&`）** =>  在变量前加 `&`，可以得到该变量的内存地址，并赋值给指针变量。例如 `p = &i` 让 `p` 指向 `i`。

   3. **解引用（`*`）** => 在**指针变量**前加 `*`，可以访问或修改它所指的那个变量。例如 `*p = 21` 会修改 `i` 的值，因为 `p` 指向 `i`。

   4. **任何一个变量（包括指针变量 `p`），只要它被声明了，它就一定在内存中占有一个属于自己的、合法的地址（`&p`）。至于它里面存的是有效地址还是 `nil`，那是它‘内容’的事，和它‘自己住哪儿’毫无关系。**

      ```go
      var p *int
      fmt.Printf("变量 p 自身的地址: %p\n", &p)  // 打印 p 自己的门牌号
      fmt.Printf("变量 p 里面存的内容: %v\n", p) // 打印 p 里面装的值（即指向的目标）
      
      变量 p 自身的地址: 0x3abb517e2068
      变量 p 里面存的内容: <nil>
      ```

3. 切片

   1. **对切片 `s` 执行 `s[low:high]` 操作时，`low` 和 `high` 的有效范围是由 `cap(s)` 决定的，而不是由 `len(s)` 决定的！**
   2. 指针是否移动，**完全由切片操作中的 `low`（起始索引）决定**，跟 `high`（结束索引）没有半点关系

4. append

   1. `append` 可能引发扩容，这时原切片和返回的切片会**指向不同的底层数组**。若之前有其他切片共享同一底层数组，扩容后原切片不受影响，但新切片已经脱离原数组，修改新切片不会影响旧切片。
   2. 即使没有扩容，对原切片和返回切片的元素修改也可能会互相可见（因为它们共享底层数组），但这种依赖很容易出错，所以通常总是用 **`s = append(s, ...)` 来保持引用一致**

6. 接口 由(值,类型)组成，两者都为空，才是nil

   1. 类型：接口具体实现了那个类型
   2. 值：指这个类型的内容

7. swith 语句

   1. 类型 switch 是一种特殊的语法结构，它的设计目的是**单纯地判断接口值的动态类型**，而不是比较某个具体值。因此，语言规范规定：类型 switch 中**不能包含表达式**。

   2. ```
      表达式 switch：switch [ SimpleStmt ; ] [ Expression ] { ... }
      类型 switch：switch [ SimpleStmt ; ] TypeSwitchGuard { ... }
      ```
